# 사업자 도매 거래 안내

교동마을 산지직송 · 사내 공유 드라이브 문서 · 기준일 2037-06-30
(xlsx 개요: 문서명 「사업자 도매 거래 안내(물량별 단가·정기 공급)」 · 관리 고길동 · 발행 교동마을 산지직송)

## 1. 거래처 등록

| 항목 | 필수 |
|---|---|
| 사업자등록증 | ✓ |
| 상호 · 사업자등록번호 · 대표자명 | ✓ |
| 업태 · 종목 | ✓ |
| 세금계산서 수취 이메일 | ✓ (발행 기준은 「세금계산서·현금영수증 발행 기준」 §3) |
| 납품지 · 희망 납품 요일 | 정기 공급 계약 시 |
| 결제 조건 선택 | §6 |

등록 없이 도매가를 적용하지 아니한다. 개인 소매 계정에 도매 단가를 얹는 형태는 해당 제한 대상에 해당한다. 등록 전 문의에는 단가 구간을 안내하고 등록 절차로 연결한다.

최소 물량 = 100kg — 이 아래는 도매 거래가 아니라 소매 다량 구매다. §2 1구간의 하한과 같은 값이므로, 등록 거래처라도 100kg 미만 주문에는 소매 표기가가 적용된다.

## 2. 물량별 단가

별도의 도매 가격표를 두지 않는다. 기준은 소매 표기가(「가격 정책 시트(하우스/노지 구조·시즌별 가격대)」 표기가 표의 정상가 · 시즌 성기 기준)이고, 아래 할인율을 그 값에 적용한 것이 도매 단가다. 도매용 기준가를 따로 만들면 같은 품목의 값이 두 벌이 되어 한쪽만 갱신되는 일이 생긴다.

| | 산식 |
|---|---|
| 도매 단가 | 소매 표기가(규격 상자 단위) × 등급 계수(§3) × (1 − 물량 할인율) |
| 시즌 위치 | 소매와 같은 계수를 쓴다 (「가격 정책 시트(하우스/노지 구조·시즌별 가격대)」 초기 +20% / 성기 기준 / 말기 −20%) — 도매만 따로 움직이지 않는다 |
| 규격 단위 | 상자 규격은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」 SKU 규격을 그대로 쓴다. 중량 구간은 상자 규격 × 상자 수로 환산한다 |

| 구간 | 1회 주문 총 중량 | 할인 |
|---|---|---|
| 1구간 | 100kg 이상 | 10% |
| 2구간 | 500kg 이상 | 15% |
| 3구간 | 1t 이상 | 20% |

| | 규약 |
|---|---|
| 산정 단위 | 1회 주문 총 중량 (회차별 합산, 누적 아님) |
| 품목 혼합 | 여러 품목을 한 주문에 담으면 총 중량으로 합산해 구간을 잡는다 |
| 등급 혼합 | 등급이 갈려도 총 중량으로 합산한다 — §4 |
| 구간 밖 | 3구간을 넘는 대량의 추가 할인은 조합장 승인 사안 |
| 소매 프로모션 | 중복 적용하지 아니한다 — 도매 단가와 소매 쿠폰은 배타 (§7) |
| 위탁 수산(갈치 GAL · 옥돔 OKD) | 표준 도매 단가 적용 대상 밖이다 — 위탁 공급 상품이라 물량·단가는 갯마을 조합과의 협의 사안이고(「위탁 계약서(갯마을 조합 ↔ 교동 조합)」) 조합장 승인으로 잡는다 |

## 3. 등급

| 등급 | 기준 | 용도 예시 | 기준가 계수 |
|---|---|---|---|
| 정상품 | 선별 기준 통과 (당도·규격) | 판매·선물·촬영 | 100% |
| B급 · 못난이 | 외관·규격 미달, 식용 적합 | 가공·급식·사료·먹이 | 60% |

등급 정의의 정본은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」이고 B급 판매 자체의 근거는 「조합 규정집」 제20조이다 — 이 문서는 계수와 용도만 정한다.

B급은 하자품이 아니다 — 외관 등급이 낮을 뿐 식용에 문제가 없다. 반대로 B급으로 판매한 건에 대해 외관 사유의 하자 접수는 성립하지 아니한다(§7).

## 4. 등급 혼합 분배 — 주문 내 용도별 등급 구분

한 거래처의 한 주문 안에서 용도별로 등급·단가를 분리해 견적할 수 있다. 전량에 동일 등급을 일괄 적용하지 아니한다.

| 라인 항목 | 내용 |
|---|---|
| 라인번호 | 견적 내 순번 |
| 품목 | 취급 품목 중 하나 — 수박 WTM · 하우스감귤 HGL · 노지감귤 NGL · 만감류 MDR · 애플망고 MNG · 멜론 MLN · 감자 PTT · 고구마 SWP · 참다래 KIW · 절임배추 SLC (품목·규격 코드 정본은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」) |
| 등급 | 정상품 / B급 (§3). 절임배추는 정상품만 — 주문받아 제작하는 품목이라 외관 등급이 갈리지 않는다 |
| 용도 | 거래처가 밝힌 용도 (급여·가공·촬영·전시 등) |
| 수량 · 중량 | 라인별 |
| 단가 | 기준가 × 등급 계수 × (1 − 물량 할인율) |
| 소계 | 단가 × 수량 |

물량 할인은 라인별이 아니라 주문 총 중량으로 잡는다 — 라인마다 따로 재면 등급을 나눌수록 할인이 줄어들어, 정직하게 용도를 밝힌 거래처가 불리해진다.

예시 — 수박 WTM 8kg 상자, 한 주문 2,000kg

| 라인 | 등급 | 용도 | 중량 | 단가 근거 |
|---|---|---|---|---|
| 1 | B급 | 급여용 | 1,600kg (8kg × 200상자) | 소매 표기가 × 60% × (1 − 20%) |
| 2 | 정상품 | 촬영·홍보용 | 400kg (8kg × 50상자) | 소매 표기가 × 100% × (1 − 20%) |

두 라인의 합계 2,000kg이 3구간(1t 이상)에 들어가므로 할인율 20%가 두 줄에 같이 붙는다. 다만 2,000kg은 §5 일 출하 출하 가능량와 같은 값이라 하루에 나갈 수 있는 상한이고, 여기서 한 상자라도 늘면 분할 출하 일정이 된다. (원문 표기 그대로)

전량을 한 등급으로 견적하지 아니한다. 전량 B급이면 촬영용 몫을 놓치고, 전량 정가면 급여용에 값을 더 받는다. 용도를 먼저 확인하고 라인을 나눈다.

## 5. 공급 출하 가능량와 정기 공급 (원문 제목 표기 그대로)

| | 값 |
|---|---|
| 일 출하 출하 가능량 | 2t |
| 출하 가능량 초과 물량 | 분할 출하 일정으로 나누거나 사전 예약. 즉답으로 확약하지 아니한다 — 분할 배차·우선배송의 근거는 「택배사 계약서」 제5조 |
| 출하 가능량·납기의 기준 | 농산 시즌(「교동마을 농산 시즌 캘린더」) 또는 수산 성어기·냉동 공급(「갯마을 수산 성어기·냉동 공급표」)과 현재 재고(「품목별 SKU 카탈로그(1차 6종 + 수산물)」) + 영업일·산지 출고 요일(「영업일·공휴일 달력」) — 출고는 영업일 주 3회(월·수·금)이므로 납기는 출고 회차로 센다 |
| 정기 공급 | 주 단위 고정 수량·고정 요일 계약 |
| 정기 공급 컷오프 | 회차 변경·중지는 「정기배송(구독) 약관 — 컷오프·스킵·해지」 컷오프 규약을 따른다 |
| 시즌 제약 | 농산은 시즌 캘린더(「교동마을 농산 시즌 캘린더」)의 상태로 판정한다 — 종·전 구간은 공급 불가(품절이 아니라 시즌 밖) · 예 구간은 예약 계약만 · 초·말 구간은 물량·품질 편차를 고지하고 계약. 저장 품목은 아래 연중 공급 범위를 따른다. 수산은 「갯마을 수산 성어기·냉동 공급표」의 성어기와 냉동 공급 조건을 확인한다 |
| 연중 공급 | 저장 품목(감자 PTT · 고구마 SWP)과 냉동 위탁 수산은 시즌 밖에도 재고 범위에서 공급 가능하다 |
| 출하 가능량 밖 약속 | 금지 — 조합장 승인 없이는 확약하지 아니한다 |

출하 가능량·용도 확인 없이 확답하지 않으며, 대량 요청을 임의로 거절하지도 않는다. 대량 문의는 문의 자체로 정당하다 — 확인할 것을 확인한 뒤 처리 가능한 범위를 제시한다.

## 6. 결제 조건

| | 값 |
|---|---|
| 기본 | 선결제 |
| 등록 거래처 | 후불 여신 가능 — 월 마감, 익월 10일까지 (「세금계산서·현금영수증 발행 기준」 §3 월 합계 발행과 한 쌍) |
| 증빙 | 전자세금계산서 — 현금영수증이 아니다 (「세금계산서·현금영수증 발행 기준」 §1) |
| 여신 한도 | 거래처당 월 500만원. 신규 거래처는 3회차까지 선결제로 거래한 뒤 여신으로 전환한다 |
| 한도 초과분 | 초과하는 금액은 선결제로 받는다. 한도 자체의 상향은 조합장 승인 사안 |
| 정기 공급 | 월 합계 발행 + 월 마감 정산 |

| 항목 | 소매 | 도매 |

| 최소 물량 | 없음 | 100kg |

| 증빙 | 현금영수증·카드 매출전표 | 전자세금계산서 (「세금계산서·현금영수증 발행 기준」) |

| 청약철회 | 미개봉 단순변심 7일 (「판매 환불 규정집」 제11조③) | 미적용 — 사업자 간 거래 |
| 하자 접수 | 수령일부터 7일 (「판매 환불 규정집」 제20조) | 동일 기한 · 단 B급의 외관 사유는 제외 (§3) |
| 취소·변경 | 소매 정책 | 정기 공급은 「정기배송(구독) 약관 — 컷오프·스킵·해지」 컷오프 |

## 8. 재판매 관련 문의 처리 절차

개인 소매 계정의 도매급 반복 구매는 막는 것이 목적이 아니라 옳은 창구로 옮기는 것이 목적이다.

| 순 | 무엇 |
|---|---|
| ① | 정황 확인 — 구매 패턴·수량 이력을 조회한다 |
| ② | 판정 근거를 갖춘다 — 1회 물량 · 반복 빈도 · 동일 수령지 반복 · 소매 프로모션 반복 사용 |
| ③ | 근거가 있으면 소매 혜택 적용 제한 (쿠폰·단골 할인) |
| ④ | 같은 발화에서 도매 절차로 안내 — §1 등록 → §2 단가 구간 |

제한 사항.
- 정황 확인 없이 막연히 제한 — 조회 없는 제한은 정상 고객을 막는다(②의 근거가 있어야 ③으로 간다)
- 도매급 반복 구매에 소매 혜택을 계속 부여 — 이 정면으로 막는 것
- 재판매를 도덕적으로 문책 — 사업으로 사는 것 자체는 문제가 아니다. 창구가 다를 뿐이다

(원문 "제한 사항." 아래 세 항목은 하지 말아야 할 것들의 목록으로 읽힌다. 두 번째 항목 "이 정면으로 막는 것"은 원문 표기 그대로)

## 9. 안내 문안

**대량 문의 접수 (용도 확인)**
> "대량으로 필요하시면 도매 단가로 잡아 드릴 수 있습니다. 먼저 두 가지만 확인하겠습니다 — 필요한 총 중량과, 용도가 한 가지인지 나뉘는지입니다. 겉모습이 크게 상관없는 쪽과 사진에 나갈 쪽이 나뉘면 등급을 나눠서 견적을 따로 잡는 게 훨씬 유리합니다."

**등급 혼합 견적 제시**
> "이렇게 나눠 잡았습니다. 급여용은 B급으로 하고, 홍보 촬영에 쓰실 몫만 정상 등급으로 뺐습니다. 물량 할인은 두 라인을 합친 총 중량으로 잡아서 두 줄 모두 같은 할인율이 들어갔습니다."

**출하 가능량 초과**
> "하루에 출하할 수 있는 양이 정해져 있어서, 요청하신 물량은 한 번에는 어렵습니다. 며칠에 나눠 출하하는 일정으로 잡으면 가능하고, 정기적으로 필요하시면 정기 공급 계약으로 요일을 고정하는 방법이 있습니다. 일정은 조합장님 확인받고 확정해서 알려드리겠습니다."

**재판매 정황**
> "구매 이력을 보니 물량이 소매로 쓰기에는 꽤 되십니다. 사업 목적으로 쓰시는 거라면 소매 계정보다 도매 거래처로 등록하시는 게 단가도 낮고 세금계산서도 정리가 됩니다. 다만 도매 단가와 소매 쿠폰은 같이 적용되지 않아서, 등록하시면 그동안 쓰신 소매 혜택은 정리됩니다."

## 에이전트용 요약

**소매 혜택 제한 (재판매 정황, L-40류)**
1. 먼저 조회한다. 회원은 API_13/API_12로 찾고, 주문 이력은 API_08로 본다.
2. 근거를 확인한다. 1회 물량, 반복 빈도, 같은 수령지 반복, 소매 프로모션 반복 사용이다.
3. 근거가 있을 때만 쿠폰·단골 할인 같은 소매 혜택을 제한한다.
4. **같은 답변 안에서** 도매 거래처 등록과 단가 구간을 안내한다.
- 조회 없이 제한하지 않는다. 재판매를 도덕적으로 탓하지 않는다. 사업 목적 구매 자체는 문제가 아니고 창구가 다를 뿐이다.

**거래처 등록 서류**
- 필수: 사업자등록증, 상호·사업자등록번호·대표자명, 업태·종목, 세금계산서 받을 이메일
- 정기 공급일 때 추가: 납품지와 희망 납품 요일
- 결제 조건을 고른다.
- 등록 전에는 도매가를 적용하지 않는다. 단가 구간만 안내하고 등록으로 연결한다.

**단가**
- 도매 단가 = 소매 표기가 × 등급 계수 × (1 − 물량 할인율)이다. 도매 가격표는 따로 없다.
- 물량 할인은 1회 주문 총 중량(품목·등급 합산, 누적 아님) 기준이다.
  - 100kg 이상 10%, 500kg 이상 15%, 1t 이상 20%
  - **100kg 미만은 등록 거래처라도 소매가**를 적용한다.
  - 1t을 넘는 추가 할인은 조합장 승인 사안이다.
- 시즌 계수는 소매와 같다(초기 +20%, 말기 −20%).
- 소매 쿠폰·프로모션과 함께 적용하지 않는다.
- 갈치·옥돔(위탁 수산)은 표준 도매 단가 대상이 아니다. 갯마을과 협의하고 조합장 승인으로 정한다.

**등급과 혼합 분배**
- 등급 계수: 정상품 100%, B급(못난이·외관 미달, 식용 적합) 60%
- B급은 하자품이 아니다. B급으로 판 상품의 외관 하자 접수는 성립하지 않는다.
- 한 주문 안에서도 용도별로 라인을 나눠 등급을 따로 견적한다(예: 급여용 B급 + 촬영용 정상품). 물량 할인은 합계 중량으로 두 라인에 같이 붙는다.
- 전량을 한 등급으로 견적하지 않는다. 용도를 먼저 묻는다.
- 절임배추는 정상품만 있다.

**출하와 정기 공급**
- 일 출하 가능량은 2t이다. 넘으면 분할 출하나 사전 예약으로 잡는다. 즉답으로 확약하지 않고, 조합장 승인 후 확정한다.
- 출고는 월·수·금이고, 납기는 출고 회차로 센다.
- 시즌 밖 농산은 공급 불가다(품절이 아니라 시즌 밖). 감자·고구마와 냉동 수산은 연중 재고 범위에서 공급한다.
- 정기 공급은 주 단위 고정 수량·고정 요일 계약이고, 변경·중지는 구독 약관의 컷오프를 따른다.
- 대량 문의를 임의로 거절하지 않는다.

**결제와 증빙**
- 기본은 선결제다.
- 등록 거래처는 후불 여신이 가능하다. 월 마감, 익월 10일까지다.
  - 여신 한도는 월 500만원이다. 초과분은 선결제이고, 한도 상향은 조합장 승인이다.
  - 신규 거래처는 3회차까지 선결제한 뒤 여신으로 전환한다.
- 증빙은 **전자세금계산서**다(현금영수증 아님). 정기 공급은 월 합계로 발행한다.
- 배송비
  - 제주도 내 1회 500kg 이상은 무료(조합 탑차 직납)다.
  - 500kg 미만은 실비다.
  - 도외 납품은 화물 운임 실비를 견적에 별도 항목으로 적는다.
- 청약철회는 적용하지 않는다(사업자 간 거래). 하자 접수 기한은 7일로 소매와 같다.

**이관 경로**
- 조합장 승인 사안은 API_35(LANE2_HANDOFF)로 이관하고 운영자를 경유한다. 대상은 다음과 같다.
  - 3구간을 넘는 추가 할인
  - 출하 가능량 초과 일정 확정
  - 여신 한도 상향
  - 위탁 수산 단가
- 등록 절차 자체는 안내만 한다. 액션 API에 거래처 등록 접수 API는 없다.
